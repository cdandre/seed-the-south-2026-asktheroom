# Ask the Room — Build Plan

## Product
Founders post short questions, others upvote + answer with 30-second wisdom. Live at https://asktheroom.org. Sign-up first (workshop default). Anonymous-toggle on questions, tag dropdown, upvotes with visible upvoter names, in-app notifications when your question gets answered.

## Architecture
- Single Worker (`worker.js`) — Hono app, per-request `createAuth(env)`, mounts `/api/auth/*` (better-auth) + `/api/*` (feature routes) + `/*` (HTML pages).
- D1 binding `DB`. Auth tables via better-auth Drizzle adapter (`auth-schema.js`, generated by integrator). App tables via `schema.sql`.
- Pages return `c.html()` with inline `<script>` calling JSON endpoints + better-auth REST.

## Features → file ownership
| # | Feature | Backend file | Frontend file | Owner |
|---|---|---|---|---|
| 1 | Auth (signup default) | `routes/auth.js` (better-auth handler) | `pages/auth.js` | frontend-1 |
| 2 | Home feed + ask form | `routes/questions.js` | `pages/home.js` | backend-1 + frontend-2 |
| 3 | Question detail + answers + upvote | `routes/answers.js`, `routes/votes.js` | `pages/question.js` | backend-2 + frontend-3 |

## Data model (app tables — `schema.sql`)
- `questions(id, author_id, author_name, anonymous, tag, body, created_at, last_answered_at)`
- `answers(id, question_id, author_id, author_name, body, created_at)`
- `upvotes(id, question_id, user_id, user_name, created_at)` — UNIQUE(question_id, user_id)
- `notifications(id, user_id, question_id, answer_id, read, created_at)` — for "notify when answered"

## Auth model
better-auth email+password. NO OAuth. NO email verification. `additionalFields.name` captured at signup. Session via cookie; routes check `c.get('auth').api.getSession({ headers: c.req.raw.headers })`.

## Tags (predefined dropdown)
`Fundraising, Hiring, Product, Sales, Operations, Other`

## Build order
1. Integrator: `drizzle-kit generate` → produces `auth-schema.js` → apply both migrations to D1 → `wrangler secret put BETTER_AUTH_SECRET` → deploy.
2. Frontend + backend fill stubs in parallel (worktrees, disjoint files).
